# Projetos de Ciência da Computação — PUC Goiás

Repositório unificado de atividades, exercícios e projetos desenvolvidos durante o curso de Ciência da Computação da PUC Goiás.

## Organização

| Pasta | Conteúdo |
| --- | --- |
| [`2026-1/`](2026-1/) | Atividades do primeiro semestre de 2026, incluindo Fundamentos de Programação, AED e provas. |
| [`Acervo-Historico/`](Acervo-Historico/) | Exercícios e projetos de períodos anteriores, com materiais de Laboratório de Programação e Estrutura de Dados. |
| [`Projetos/JogoDaForca/`](Projetos/JogoDaForca/) | Jogo da forca desenvolvido com frontend React, backend Python e ambiente Docker. |
| [`Projetos/Microservico-Produto/`](Projetos/Microservico-Produto/) | Microserviço de produtos para a disciplina de Sistemas Distribuídos, desenvolvido em .NET. |
| [`Projetos/ServidoresDeHorarioSocket/`](Projetos/ServidoresDeHorarioSocket/) | Sistema distribuído em C# com três servidores de horário TCP e um cliente Socket. |
| [`Projetos/Prova03-Fundamentos-4/`](Projetos/Prova03-Fundamentos-4/) | Soluções em Python para a terceira prova de Fundamentos de Programação 4. |
| [`Projetos/Compilador-C-lasse-Trabalhadora/`](Projetos/Compilador-C-lasse-Trabalhadora/) | Compilador que traduz a linguagem temática C-lasse Trabalhadora para C padrão. |
| [`Projetos/SisBiblio/`](Projetos/SisBiblio/) | Sistema de biblioteca em Java, com persistência em MySQL. |
| [`Projetos/IA-Python-Ciencia-da-Computacao-PUC-Goias/`](Projetos/IA-Python-Ciencia-da-Computacao-PUC-Goias/) | Atividades de Inteligência Artificial em Python: análise de dados, clustering, reconhecimento facial e classificação de malária. |
| [`Projetos/agenda-contatos/`](Projetos/agenda-contatos/) | Agenda de contatos da disciplina de Tecnologia de Construção de Software I, para demonstrar o fluxo com Git, GitHub e GitFlow. |

## Tecnologias

Os materiais incluem principalmente Python, C/C++, Java, JavaScript/HTML/CSS e .NET, além de projetos desenvolvidos com Qt, React, Docker e MySQL.

Cada atividade permanece em sua pasta original para preservar o contexto de disciplina, período e enunciado.
