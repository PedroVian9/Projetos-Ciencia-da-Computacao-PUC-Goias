# Projetos de Ciência da Computação — PUC Goiás

Repositório unificado de atividades, exercícios e projetos desenvolvidos durante o curso de Ciência da Computação da PUC Goiás.

## Organização

| Pasta | Conteúdo |
| --- | --- |
| [`2026-1/`](2026-1/) | Atividades do primeiro semestre de 2026, incluindo Fundamentos de Programação, AED e provas. |
| [`Acervo-Historico/`](Acervo-Historico/) | Exercícios e projetos de períodos anteriores, com materiais de Laboratório de Programação e Estrutura de Dados. |

## Tecnologias

Os materiais incluem principalmente Python e C/C++, além de projetos desenvolvidos com Qt.

Cada atividade permanece em sua pasta original para preservar o contexto de disciplina, período e enunciado.
