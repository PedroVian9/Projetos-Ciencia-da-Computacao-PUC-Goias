# IA 3 — Reconhecimento facial

Experimento de reconhecimento facial com a base ORL Faces. O código carrega as imagens, reduz a dimensionalidade com PCA, treina um classificador SVM e apresenta classificação, matriz de confusão e projeção t-SNE.

## Execução

```bash
pip install opencv-python numpy matplotlib seaborn scikit-learn
python main.py
```

Execute o comando dentro desta pasta para que o diretório `orl_faces/` seja localizado.
