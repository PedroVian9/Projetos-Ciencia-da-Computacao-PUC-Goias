# IA 2 — Segmentação de clientes com K-Means

Aplicação de agrupamento sobre a base `Mall_Customers.csv`. Inclui pré-processamento, escolha do número de clusters com método do cotovelo e silhouette score, visualizações 2D/3D e estatísticas por grupo.

## Execução

```bash
pip install pandas matplotlib scikit-learn
python main.py
```

Execute o comando dentro desta pasta para que a base CSV seja encontrada.
