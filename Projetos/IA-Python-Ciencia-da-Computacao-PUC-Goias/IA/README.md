# IA — Análise de consumo de cerveja

Projeto de análise exploratória da base `beer_consuption.csv`. O programa apresenta um menu interativo para consultar observações, dimensões, valores ausentes, tipos de dados, correlações, estatísticas descritivas e gráficos.

## Execução

```bash
pip install pandas matplotlib seaborn
python analise_cerveja.py
```

Execute o comando dentro desta pasta para que a base CSV seja encontrada.
